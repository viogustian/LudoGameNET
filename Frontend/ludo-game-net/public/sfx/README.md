# File suara yang dibutuhkan

Taruh 6 file audio di folder ini dengan nama PERSIS seperti berikut
(format .mp3, durasi pendek ~0.2–1.5 detik):

| Nama file            | Dipakai saat...                                    |
|-----------------------|-----------------------------------------------------|
| `game-start.mp3`      | Game baru dimulai (setelah pilih pemain)             |
| `dice-roll.mp3`       | Tombol "Lempar Dadu" ditekan                         |
| `piece-move.mp3`      | Bidak berhasil melangkah                             |
| `piece-capture.mp3`   | Bidak lawan tertangkap / dimakan                     |
| `piece-finish.mp3`    | Bidak sampai di kotak finish                         |
| `victory.mp3`         | Ada pemain yang memenangkan permainan                |

Rekomendasi sumber gratis (cek lisensinya, utamakan CC0 / royalty-free):
- https://mixkit.co/free-sound-effects/
- https://freesound.org/
- https://opengameart.org/

Kalau salah satu file belum ada, aplikasi tetap berjalan normal tanpa
suara untuk aksi tersebut (tidak akan error) — jadi kamu bisa menambahkan
satu per satu.
